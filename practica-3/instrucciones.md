Instrucciones:
* Aplicar “fuerza bruta” sobre una serie de cadenas cifradas, deberán poner la cadena original junto con su llave.
* Para césar tendrán que usar el comando `tr`
* Para Vigénere pueden programarlo sin hacer ningún tipo de import o método que resuelva directamente el algoritmo, es decir, desde cero.
* Se deberá adjuntar el comando ejecutado y código.
* Pueden aplicar cualquier método de análisis pero tendrán que reportarlo, incluso si es fuerza bruta simple
* Por último, poner a prueba cualquier agente de IA para que descifre alguna cadena dando pistas poco a poco sin dar la llave
* Algunas de las llaves son las siguientes: star, pinamar, lazy, lagrima, passenger, diente.
